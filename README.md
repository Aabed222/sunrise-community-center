# Sunrise Community Center

Official website for **Sunrise Community Center** and **Sunrise Academy** (Islamic private school, Pre-K through grade 6) in Bakersfield, California.

- Nonprofit: 501(c)(3) · EIN 83-2069619
- President: Bassam Abed
- Campus: 3212 Jewetta Ave, Bakersfield, CA 93312
- Mailing: 1005 Stine Road, Bakersfield, CA 93309

## Tech

- Next.js (App Router) · TypeScript · Tailwind CSS
- Hosted on Vercel

## Local development

1. Install dependencies
2. Start the development server (`dev` script)
3. Open http://localhost:3000
4. Create a production build with the `build` script
